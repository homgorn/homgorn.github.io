# Парсинг и скрапинг данных

Автоматический сбор данных с любых веб-источников. Собираю информацию, которую невозможно или долго собирать вручную.

## Что парсим

- **Товары**: названия, цены, фото, описания, характеристики
- **Категории**: структура каталогов
- **Контент**: статьи, отзывы, комментарии
- **Цены**: мониторинг конкурентов
- **Контакты**: телефоны, e-mail, адреса

## Источники

- Интернет-магазины
- Маркетплейсы (Wildberries, Ozon, Я.Маркет)
- Каталоги и агрегаторы
- Доски объявлений
- Социальные сети
- Любые другие сайты

## Форматы выгрузки

- Excel (.xlsx)
- CSV
- XML
- JSON
- YML для маркетплейсов
- SQL для баз данных
