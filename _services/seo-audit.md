# Технический SEO-аудит сайта

Комплексный технический аудит для выявления проблем, мешающих продвижению сайта в поиске.

## Что проверяю

### Индексация

- Статус индексации в Яндекс и Google
- robots.txt и метатеги
- Карта сайта XML
- Дубли и битые ссылки
- Канонические страницы

### Скорость и производительность

- PageSpeed Insights
- Core Web Vitals (LCP, FID, CLS)
- Оптимизация изображений
- Кэширование
- Сжатие ресурсов

### Адаптивность

- Mobile-Friendly Test
- Верстка для мобильных
-Touch-элементы
- Читаемость на телефонах

### Безопасность

- SSL-сертификат
- Mixed content
- Вредоносный код
- Редиректы

### Структура

- ЧПУ и URL
- Заголовки H1-H6
- Метатеги
- Микроразметка Schema.org

## Результат

- Подробный отчет
- Список проблем с приоритетами
- Рекомендации по исправлению
- Пошаговый план
